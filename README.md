# Homebrew Tap for Proton Drive Sync

This tap contains the Homebrew formula for [proton-drive-sync](https://github.com/DamianB-BitFlipper/proton-drive-sync).

## Installation

```bash
brew tap DamianB-BitFlipper/tap
brew install proton-drive-sync
```

## Post-Installation

Run the setup wizard to configure authentication and service:

```bash
proton-drive-sync setup
```

## Updating

```bash
brew upgrade proton-drive-sync
```

## Uninstalling

```bash
brew uninstall proton-drive-sync
brew untap DamianB-BitFlipper/tap
```
